# 📂 Windows Downloads Auto-Organizer

A simple desktop automation built with **Microsoft Power Automate Desktop** that scans the `Downloads` folder and automatically moves files into an `Organized` directory.

## 🚀 How to Use
1. Install [Power Automate for Desktop](https://powerautomate.microsoft.com/).
2. Create a new flow named `Sort Downloads`.
3. Open `flow.txt` from this repository, copy the text (`Ctrl + C`).
4. Paste (`Ctrl + V`) directly into your Power Automate canvas.
5. Click **Run (Play)**!
