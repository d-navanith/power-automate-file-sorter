# 📂 Smart Downloads Organizer

An automated Windows desktop workflow built with **Microsoft Power Automate Desktop** that keeps your `Downloads` folder organized without manual effort.

---

## 🌟 Versions

### 🔹 Version 2 (Current) — `flow_v2_smart.txt`
* **Smart Extension Filtering:** Uses `If` and `Else If` condition logic.
* Automatically sorts `.pdf` files into `Downloads\PDFs`.
* Automatically sorts `.png` images into `Downloads\Images`.
* Prevents data loss using safe file handling.

### 🔹 Version 1 — `flow_v1_basic.txt`
* Basic loop that moves all loose downloads into a single `Organized` folder.

---

## 🚀 How to Run
1. Open **Power Automate for Desktop**.
2. Create a new flow named `Smart Downloads Organizer`.
3. Open `flow_v2_smart.txt` from this repository and copy all text (`Ctrl + A`, `Ctrl + C`).
4. Click on your Power Automate canvas and paste (`Ctrl + V`).
5. Click **Save** and hit **Run (Play ▶)**!
